## Descripción
Sistema de stock por consola hecho en Python con MySQL. Permite
agregar, listar, modificar y borrar productos y categorías (CRUD).
Usa dos tablas relacionadas: categorias y productos.

## Cómo usarlo
1. Ejecutar dbf/estructura.sql en MySQL para crear la base de datos.
2. Instalar el conector: python -m pip install mysql-connector-python
3. Poner la contraseña de MySQL en src/Tp_final_crud.py
4. Ejecutar: python src/Tp_final_crud.py
